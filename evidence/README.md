# Evidence

Sanitised test receipts for experiments in [../experiments/](../experiments/) go here.

Use a matching subdirectory name, with the tested revision, exact commands, inputs, observed output, and honest limitations. Keep the evidence compact and reproducible. Never publish account tokens, private URLs or contents, personally identifying data, or machine-specific sensitive logs.

Evidence must describe real observed execution; do not label synthetic examples or model self-reports as independent proof.
